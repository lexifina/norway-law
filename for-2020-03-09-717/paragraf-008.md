# § 8. Ikrafttredelse
Forskriften trer i kraft fra den blir kunngjort i Norsk Lovtidend.
Samtidig oppheves følgende forskrifter:
- forskrift 2. september 2014 nr. 1140 om særskilte beskyttelsestiltak ved import av visse fôrvarer og næringsmidler fra tredjestater på grunn av aflatoksinrisiko,
- forskrift 2. september 2014 nr. 1141 om særskilte beskyttelsestiltak ved import av visse næringsmidler fra tredjestater på grunn av risiko for plantevernmidler,
- forskrift 20. februar 2017 nr. 203 om særskilte beskyttelsestiltak ved import av visse næringsmidler fra tredjestater på grunn av mikrobiologisk forurensning,
- forskrift 25. februar 2015 nr. 161 om særskilte beskyttelsestiltak ved import av guarkjernemel fra India.
