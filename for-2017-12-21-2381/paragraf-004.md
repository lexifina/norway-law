# § 4. Gyldigheten av godkjenninger som sakkyndig virksomhet type A-1 og sakkyndig person type B-1
(1) Godkjenningen er bare gyldig når den sakkyndige virksomheten type A-1 eller den sakkyndige personen type B-1 står oppført på Sjøfartsdirektoratets oversikt over godkjente sakkyndige virksomheter og personer.
(2) Hvis sakkyndig virksomhet type A-1 eller sakkyndig person type B-1 på forespørsel ikke dokumenterer samsvar med § 3 første eller andre ledd, kan Sjøfartsdirektoratet slette den sakkyndige virksomheten eller personen fra oversikten.
