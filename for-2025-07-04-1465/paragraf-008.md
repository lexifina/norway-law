# § 8. Kunnskap om og arbeid med sosiale problemer – Ferdigheter
Kandidaten
a) kan anvende faglig kunnskap om sosiale problemer, overganger og livskriser for å forebygge utenforskap og fremme mestring og endring i samarbeid med enkeltpersoner, familier, grupper og samarbeidspartnere
b) kan anvende ulike metodiske tilnærminger på individ-, gruppe- og samfunnsnivå innenfor ulike tjenesteområder
c) kan anvende faglig kunnskap om relasjon og kommunikasjon i veiledning, motivasjons- og endringsarbeid og veilede brukere, pasienter, pårørende og fagpersoner
d) kan anvende faglig kunnskap om arbeidsrettet inkludering i møte med arbeidssøkere, arbeidsgivere og samarbeidspartnere
e) kan anvende faglig kunnskap for å identifisere og mobilisere ressurser og, i samarbeid med mennesker i sårbare livssituasjoner bidra til å skape håp
f) kan anvende metoder i familie- og nettverksarbeid og tidlig innsats
g) kan anvende faglig kunnskap og metoder for medvirkning og samarbeid med barn, unge, foreldre, og foresatte om hverdagsliv og om vanskelige tema på en måte som ivaretar deres interesser og rettigheter og sikrer barnets beste
h) kan anvende faglig kunnskap for å vurdere og avklare bekymringsmeldinger og undersøke omsorgssituasjonen til barn og unge og iverksette, følge opp, koordinere og evaluere tiltak
i) kan anvende faglig kunnskap og arbeide tverrfaglig i møte med mennesker som utøver og utsettes for vold og overgrep
j) kan samtale med barn om tema som omsorgssvikt, vold og overgrep
k) kan vurdere og sette inn tiltak som forebygger og reduserer konsekvensene av vold, overgrep og omsorgssvikt, overfor barn og voksne i alle aldre
l) kan beherske digitale verktøy og reflektere over faglige og etiske perspektiver knyttet til anvendelsen av disse i sosialt arbeid
m) kan beherske metoder i samfunnsarbeid som fremmer makt, innflytelse, deltakelse og representasjon
n) kan beherske aktuelle metoder for kartlegging, dokumentasjon, analyse og beslutningstaking, og ta hensyn til ulike språklige barrierer i kommunikasjon og formidling
o) kan reflektere over, håndtere og redusere uønskede hendelser og konfliktsituasjoner i sitt arbeid
p) kan reflektere over og anvende kunnskap som bidrar til et likeverdig tjenestetilbud for samiske brukere.
