# § 18
Sysselmesteren kan på Svalbard innføre båndtvang for hund. Båndtvangen kan begrenses til bestemte områder, bestemte tider og til bestemte hunder eller hundetyper.
Sysselmesteren kan avlive eller kreve avlivet hund som streifer om i strid med fastsatt båndtvang eller som representerer en fare for mennesker eller dyr.
Departementet kan vedta tilsvarende forskrifter for Jan Mayen.
