# § 29. Fuglereservater
Svalbard har følgende naturreservater for fugl:
a) Sørkapp naturreservat for fugl som omfatter Sørkappøya og øyene og skjærene sørøstover fra Øyrlandet
b) Dunøyane naturreservat for fugl som omfatter alle øyer og skjær vest for Dunøysundet
c) Isøyane naturreservat for fugl som omfatter nordre Isøya og Isøykalven
d) Olsholmen naturreservat for fugl som omfatter Olsholmen
e) Kapp Linné naturreservat for fugl som omfatter området vest for linjen fra Randvika til sørøstre ende av Fyrstesjøen unntatt Isfjord Radios stasjonsområde
f) Boheman naturreservat for fugl som omfatter småøyene sør for Bohemanflya
g) Gåsøyane naturreservat for fugl som omfatter Gåsøyane
h) Plankeholmane naturreservat for fugl som omfatter Plankeholmane
i) Forlandsøyane naturreservat for fugl som omfatter Forlandsøyane
j) Hermansenøya naturreservat for fugl som omfatter Hermansenøya
k) Kongsfjorden naturreservat for fugl som omfatter Mietheholmen, Prins Heinrichøya, Lovenøyane og Eskjeret
l) Blomstrandhamna naturreservat for fugl som omfatter ytre og indre Breøyane
m) Guissezholmen naturreservat for fugl som omfatter holmene ved Kapp Guissez
n) Skorpa naturreservat for fugl som omfatter holmene ved Harpunodden
o) Moseøya naturreservat for fugl som omfatter Moseøya
p) Liefdefjorden naturreservat for fugl som omfatter Andøyane, Stasjonsøyane, Måkeøyane og Lernerøyane med omkringliggende holmer.
Naturreservatene for fugl, som vist på kart i vedlegg 1, omfatter sjøområdet ut til 300 meter fra land eller skjær ved laveste vannstand.
