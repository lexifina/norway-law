# § 8-2. Fartsgrenser på sjøen i Haugesund kommune
5 knop er høyeste tillatte fart for næringsfartøy i Røvær syd for Mjåsund vestre til Torgersnes, innenfor rette linjer trukket mellom posisjonene
1) N 59° 26.62′, Ø 5° 05.46′ og N 59° 26.62′, Ø 5° 05.52′
2) N 59° 26.31′, Ø 5° 05.69′ og N 59° 26.29′, Ø 5° 05.69′
3) N 59° 26.09′, Ø 5° 05.62′ og N 59° 26.10′, Ø 5° 05.74′.
5 knop er høyeste tillate fart for næringsfartøy i Smedasundet innenfor linjene trukket mellom følgende posisjoner
1) N 59° 25.250′, Ø 5° 14.870′ og N 59° 25.200′, Ø 5° 14.970′
2) N 59° 24.840′, Ø 5° 15.360′ og N 59° 24.760′, Ø 5° 15.360′
3) N 59° 24.339′, Ø 5° 16.340′ og N 59° 24.210′, Ø 5° 16.290′
4) N 59° 24.080′, Ø 5° 16.540′ og N 59° 24.101′, Ø 5° 16.740′.
8 knop er høyeste tillatte fart for næringsfartøy i Vibrandsøysundet syd for nordligste punkt på Killingøy og ned til nordligste punkt av Garpeskjærskaien, innenfor rette linjer trukket mellom posisjonene
1) N 59° 25.33′, Ø 5° 14.54′ og N 59° 25.35′, Ø 5° 14.82′
2) N 59° 25.25′, Ø 5° 14.87′ og N 59° 25.20′, Ø 5° 14.97′
3) N 59° 24.84′, Ø 5° 15.36′ og N 59° 24.76′, Ø 5° 15.36′
4) N 59° 24.73′, Ø 5° 15.14′ og N 59° 24.74′, Ø 5° 15.30′.
5 knop er høyeste tillatte fart for fritidsfartøy i hoved- og biled i Røvær syd for Mjåsund vestre til Torgersnes, innenfor rette linjer trukket mellom posisjonene
1) N 59° 26.62′, Ø 5° 05.46′ og N 59° 26.62′, Ø 5° 05.52′
2) N 59° 26.31′, Ø 5° 05.69′ og N 59° 26.29′, Ø 5° 05.69′
3) N 59° 26.09′, Ø 5° 05.62′ og N 59° 26.10′, Ø 5° 05.74′.
8 knop er høyeste tillatte fart for fritidsfartøy i hoved- og biled i Vibrandsøysundet syd for nordligste punkt på Killingøy og ned til nordligste punkt av Garpeskjærskaien, innenfor rette linjer trukket mellom posisjonene
1) N 59° 25.33′, Ø 5° 14.54′ og N 59° 25.35′, Ø 5° 14.82′
3) N 59° 25.25′, Ø 5° 14.87′ og N 59° 25.20′, Ø 5° 14.97′
2) N 59° 24.84′, Ø 5° 15.36′ og N 59° 24.76′, Ø 5° 15.36′.
