# § 10-5. Fartsgrenser på sjøen i Porsgrunn kommune
5 knop er høyeste tillatte fart for næringsfartøy i Brevik innenfor rette linjer trukket mellom posisjoneneog
1) N 59° 03.109′, Ø 9° 41.929′ og
2) N 59° 03.108′, Ø 9° 42.067′,
3) N 59° 03.308′, Ø 9° 42.301′ og
4) N 59° 03.186′, Ø 9° 42.484′.
5 knop er høyeste tillatte fart for næringsfartøy i følgende områder:
a) I Risøysundet innenfor rette linjer trukket mellom posisjonene
1) N 59° 01.514′, Ø 9° 45.430′
2) N 59° 01.443′, Ø 9° 45.810′
3) N 59° 01.869′, Ø 9° 45.936′
4) N 59° 01.857′, Ø 9° 46.010′.
b) I Ulesund innenfor rette linjer trukket mellom posisjonene
1) N 59° 04.138′, Ø 9° 43.274′
2) N 59° 03.972′, Ø 9° 43.244′
3) N 59° 03.951′, Ø 9° 44.151′
4) N 59° 03.889′, Ø 9° 44.127′.
c) I Sandøysundet innenfor rette linjer trukket mellom posisjonene
1) N 59° 03.731′, Ø 9° 43.351′
2) N 59° 03.668′, Ø 9° 43.297′
3) N 59° 03.775′, Ø 9° 44.282′
4) N 59° 03.551′, Ø 9° 44.492′.
