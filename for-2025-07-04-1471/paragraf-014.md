# § 14. Kompetanseområdet lyd og persepsjon – Ferdighet
Kandidaten
a) kan anvende faglig kunnskap om sammenhengen mellom lydens egenskaper og hvordan den oppfattes
b) kan anvende faglig kunnskap for å forstå bakgrunnen for målinger av ulike nivå i hørselssystemet og konsekvenser av hørselstap
c) kan anvende faglig kunnskap for å forstå hvordan ulike hørselstap og redusert kognitiv funksjon kan påvirke evne til å oppfatte tale, og hvilke begrensninger hørselstekniske hjelpemidler kan ha.
