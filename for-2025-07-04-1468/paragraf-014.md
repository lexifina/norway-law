# § 14. Psykologisk utredning og behandling – Ferdigheter
Kandidaten
a) kan selvstendig gjennomføre grunnleggende strukturerte psykologiske og nevropsykologiske utredninger som grunnlag både for diagnostiske vurderinger og kasusformuleringer, og for å utarbeide behandlingsplaner med anbefalinger om videre tiltak og behandling
b) kan dokumentere utredning, diagnostisering og behandling i pasientjournal, i tråd med gjeldende regelverk
c) kan selvstendig gjennomføre samtaler med barn som pårørende, og som utsatt for vold, overgrep og omsorgssvikt
d) kan bruke ulike metoder for å sikre tilbakemeldinger fra pasienter om behandlingsresultat, -prosess og allianse, og benytte disse for å tilpasse behandlingstilbudet
e) kan analysere og forholde seg kritisk til komplekse faglige spørsmål, ulike roller og muligheter i arbeidet med ulike typer psykiske lidelser, og til samhandling og oppgavefordeling mellom tjenestenivåene
f) kan bruke relevante metoder for å identifisere mennesker med sosiale og helsemessige problemer inkludert omsorgssvikt, mobbing, vold, overgrep, rus- og sosioøkonomiske problemer, og sette inn nødvendige tiltak og/eller behandling, eller henvise videre ved behov
g) kan på en selvstendig måte bruke relasjonelle ferdigheter som er sentrale i etablering og opprettholdelse av terapeutiske allianser og samarbeidsallianser
h) kan selvstendig anvende grunnprinsippene for psykososiale intervensjoner i kriser.
