# § 3-10. Særlege begrensningar i opptaksretten
Søkjarar som er tatt opp ved eit studieprogram ved Skrivekunstakademiet i Hordaland, og som har trekt seg og/eller blitt utestengt frå same program to år på rad, kan ikkje søkje nytt opptak det følgjande året. Avvisning av søknad etter denne paragrafen kan påklagast til styrets klagenemnd.
