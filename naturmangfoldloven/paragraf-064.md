# § 64. (gransking)
Når det er nødvendig for å utføre gjøremål etter loven, skal tilsynsmyndigheten eller politiet ha uhindret adgang til eiendom der det foregår virksomhet som kan påvirke naturmangfoldet, eller der naturmangfoldet kan antas å være påvirket. Tilsynsmyndigheten kan også kreve å få lagt frem og granske dokumenter eller annet materiale som kan ha betydning for gjøremål etter loven.
