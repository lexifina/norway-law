# § 8. Barn, unge og deres familie/omsorgsgivere – Ferdigheter
Kandidaten
a) kan anvende kunnskapsbaserte metoder for å fremme informerte helsevalg, mestring og livskvalitet hos barn, unge og deres familie/omsorgsgivere
b) kan bruke relevante metoder for å selvstendig kartlegge og vurdere barn og unges helse, identifisere utviklingsavvik, sykdom og funksjonsnedsettelse, og iverksette tiltak etter behov
c) kan forebygge, identifisere og avverge psykososiale belastninger, omsorgssvikt, vold, seksuelle overgrep, rusmisbruk, selvskading og selvmordsatferd og iverksette relevante tiltak
d) kan forebygge, avdekke og følge opp fysiske og psykiske helseplager hos barn og unge
e) kan selvstendig veilede om, rekvirere og administrere prevensjonsmidler, herunder langtidsvirkende prevensjonsmidler
f) kan selvstendig veilede om ernæring, ernæringsutfordringer, amming og vekst og henvise videre ved behov
g) kan anvende kunnskap om de vanligste fysiologiske og patofysiologiske prosesser, sykdom og sykdomslære hos nyfødte, barn og ungdom
h) kan anvende kunnskap om barn og unges bruk av digitale arenaer for å forstå og iverksette tiltak ved behov.
